HR Training Request

Streamline external employee training & certifications with a two-step approval workflow

Security Design & Hierarchy

The module defines a dedicated Training Requests security category with three implied groups:

  • Training Requester: Base access to create, edit (in draft), submit, and view own requests.
  • Training Manager Approver: Implies Requester access. Can approve or reject submitted requests for direct reports.
  • Training HR Approver: Implies Manager Approver access. Final approval authority for all company training requests.

Workflow Enforcement & State Machine

The app implements a strict state machine to enforce business processes:

Key Features

Multi-Company Support
Built using company-specific default parameters. Record rules enforce company boundaries for HR users automatically.
Interactive Rejection Wizard
Requires non-empty feedback when rejecting a request, logging reasons directly into the Chatter notes.
Live-Related Organization Hierarchy
Manager fields automatically sync with HR configurations. Changing an employee's organizational manager updates routing instantly.
Interactive OWL Dashboard
Responsive client action providing role-aware KPIs, actionable queue counters, and state distribution statistics.
